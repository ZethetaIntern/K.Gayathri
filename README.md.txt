# Bond Risk & Key Rate Duration Analysis

## Project Overview

This project analyses bond portfolio interest-rate risk using
bond mathematics, duration, convexity, DV01, Key Rate Duration,
scenario analysis, and machine learning techniques.

## Objectives

- Analyse bond price and interest-rate sensitivity
- Calculate duration and convexity
- Calculate DV01
- Analyse Key Rate Duration across maturity buckets
- Evaluate interest-rate scenario impacts
- Apply machine learning for risk analysis

## Tools & Technologies

- Jupyter Notebook
- Microsoft Excel
- Power BI
- Machine Learning
